Downgrade Geometry Dash from 2.209 to 2.2081

Pick your platform below. Windows, macOS and Linux use Steam; Android uses Aurora Store; iOS works differently.

App ID322170
Depot: Windows / Linux322171
Manifest: Windows / Linux3816559102876907245
Depot: macOS322172
Manifest: macOS8780295549609362522
Android version code41
Why people do this: mods (Geode) often lag behind a new game version, so rolling back to 2.2081 gets them working again.

Windows

Steam console method. You must own Geometry Dash on Steam.

0 Back up your save (recommended)

Press Win + R, paste the path below, and copy the whole folder somewhere safe. Also sync your account data to the cloud in-game.

%localappdata%\GeometryDash

1 Close the game and open the Steam console

Fully close Geometry Dash. Then press Win + R and run:

steam://open/console

Steam opens on its Console tab. If nothing happens, open Steam first and run it again.

2 Download the 2.2081 files

Paste this into the Steam console and press Enter:

download_depot 322170 322171 3816559102876907245

Wait until the console says the download is complete. The files land in:

Steam\steamapps\content\app_322170\depot_322171

Typical full path: C:\Program Files (x86)\Steam\steamapps\content\app_322170\depot_322171 (your Steam library may be elsewhere).

3 Open the game folder

  1. In Steam, right-click Geometry Dash → Properties.
  2. Go to Installed Files → Browse.

Keep this window open next to the depot folder from step 2.

4 Copy the old files over the new ones

  1. Open the depot_322171 folder and select everything inside (Ctrl + A).
  2. Drag or paste it into the Geometry Dash game folder.
  3. Choose Replace the files in the destination when asked.
If you use mods, keep a copy of your geode folder and mod files first. Overwriting can break an install that was built for 2.209.

5 Stop Steam from updating it again

  1. Open the game folder (step 3), then go up two levels (Geometry Dash → common) to reach steamapps.
  2. Right-click appmanifest_322170.acf → Properties → tick Read-only → OK.
If the game still gets updated, launch it by running GeometryDash.exe directly from its folder instead of through Steam.

6 Launch and check the version

Start Geometry Dash and confirm the version shown in-game is 2.2081.

Done. If you use Geode, install a Geode build and mods that support 2.2081.

Updating back to 2.209

  1. Untick Read-only on appmanifest_322170.acf.
  2. In Steam: Geometry Dash → Properties → Installed Files → Verify integrity of game files.

Troubleshooting

The game crashes on launch
  • Reinstall Geode and your mods for 2.2081, or temporarily move the Geode files out of the game folder to test the vanilla game.
  • Make sure you copied all files from the depot, not just the .exe.
The console command does nothing or errors
  • Make sure you're logged in to the Steam account that owns Geometry Dash.
  • Check for typos; the Windows manifest ID is 3816559102876907245.

macOS

Steam console method with the Mac depot. You must own Geometry Dash on Steam.

Geode data will be lost when you downgrade on a Mac. Back up anything important first, and sync your account data to the cloud in-game.

1 Open the Steam console

Type this into the address bar of Safari (or another browser) and allow it to open Steam:

steam://open/console

2 Download the Mac files

Paste into the console, press Enter, and wait for the download to finish. Note the Mac depot ID (322172) and manifest differ from Windows.

download_depot 322170 322172 8780295549609362522

3 Show hidden files in Finder

Open Finder and press Cmd + Shift + . to show hidden files (press it again later to hide them).

4 Copy GeometryDash.app into the game folder

Copy GeometryDash.app from the download location:

~/Library/Application Support/Steam/Steam.AppBundle/Steam/Contents/MacOS/steamapps/content/app_322170/depot_322172/GeometryDash.app

Paste it here and choose Replace when asked:

~/Library/Application Support/Steam/steamapps/common/Geometry Dash
This assumes Steam is installed in the default location. If your game is stored elsewhere, adjust the paths.

5 Stop Steam from updating it again

  1. In Finder, go to ~/Library/Application Support/Steam/steamapps.
  2. Right-click appmanifest_322170.acf → Get Info → tick Locked.

6 Launch and check the version

Launch Geometry Dash through Steam and confirm it shows 2.2081. If you use Geode, install a build that supports 2.2081.

If Steam updates the game anyway, launch GeometryDash.app directly from the game folder, or temporarily remove Locked, update, then repeat this guide.

Updating back to 2.209

  1. Remove Locked from appmanifest_322170.acf.
  2. In Steam: right-click Geometry Dash → Properties → Installed Files → Verify integrity of game files.

Linux

Uses DepotDownloader because the Steam console isn't used here. You must own Geometry Dash on Steam.

1 Get DepotDownloader

Download it from the DepotDownloader releases page and extract the ZIP. Pick the build for your CPU:

  • linux-x64: 64-bit Intel/AMD
  • linux-arm64: 64-bit ARM
  • linux-arm: 32-bit ARM

Then open a terminal in the extracted folder (cd into it).

2 Download the 2.2081 depot

Option A: log in with your Steam username and password (replace the placeholders):

./DepotDownloader -app 322170 -depot 322171 -manifest 3816559102876907245 -username [USERNAME] -password [PASSWORD]

Option B: log in with a Steam Guard QR code instead of a password:

./DepotDownloader -app 322170 -depot 322171 -manifest 3816559102876907245 -qr

Add -remember-password to option A if you want it to remember your login. DepotDownloader is open source and only sends your login to Steam, but it's still a third-party tool, so use it at your own discretion. Wait for the download to finish.

3 Copy the files into the game folder

  1. In the folder DepotDownloader created (322170), open the folder inside it and copy everything inside.
  2. In Steam: right-click Geometry Dash → Manage → Browse local files.
  3. Paste the files there and replace existing files when asked.

4 Stop Steam from updating it again

From the game folder, go up two levels (Geometry Dash → common) to steamapps, open a terminal there, and run:

chmod 444 appmanifest_322170.acf

5 Launch and check the version

Launch through Steam and confirm 2.2081. If you use Geode, install a build that supports 2.2081.

If Steam updates the game anyway, launch GeometryDash.exe from the game folder, or run chmod 644 appmanifest_322170.acf to allow an update, then repeat this guide.

Updating back to 2.209

  1. Run chmod 644 appmanifest_322170.acf in the steamapps folder.
  2. In Steam: Geometry Dash → Properties → Installed Files → Verify integrity of game files.

Android

Uses Aurora Store to install an older Play Store build. You must own Geometry Dash on Google Play.

Read first: vanilla (unmodded) save data is erased when you uninstall, so save your account data to the cloud first. This method is technically against Google's terms of service, so proceed at your own risk.

1 Save your data to the cloud

In Geometry Dash, open your account settings and save your data to the cloud before doing anything else.

2 Install Aurora Store

Download and install the latest APK from the official Aurora Store files page. Android may ask you to allow installs from your browser or file manager.

3 Uninstall Geometry Dash

Uninstall the current Geometry Dash from your device. Android won't let a normal install replace a newer version with an older one.

Geode save data is not erased, but all vanilla Geometry Dash save data is.

4 Download version 2.2081 with Aurora

  1. Open Aurora Store and sign in with the same Google account you bought Geometry Dash with.
  2. Search for Geometry Dash and open its page.
  3. Tap the three-dot menu (top right) → Manual Download.
  4. Enter this version code and tap Install: 
    41
  5. When Android prompts you, tap Install a second time.

5 Restore your save

Open Geometry Dash (or Geode) and restore your cloud save. You should not lose progress. Geode Launcher can now load Geometry Dash.

Done. Check the version in-game shows 2.2081.

Updating back to 2.209

Update Geometry Dash through Aurora Store.

Safety tip

You'll find many "Geometry Dash 2.2081.apk" files on sites like itch.io. Those are unofficial uploads, so avoid them. The Aurora method above downloads the build tied to your own purchase.

iOS (iPhone / iPad)

Downgrading on iOS is much more restricted than on other platforms.

The old manual method for downgrading Geometry Dash on iOS no longer works.

What works now

If you use Geode on iOS, Geode Launcher automatically downloads the latest version of Geometry Dash that it supports (currently 2.2081). So you don't need to downgrade by hand: install and open Geode Launcher and let it fetch the supported version.

  • Without Geode, I couldn't find a working way to roll back the App Store version.
  • Downgrading your whole iOS system is not a fix for this and carries its own risks, so it isn't covered here.
  • Avoid random "Geometry Dash IPA" download sites; they're unofficial and can be unsafe.
